# Книга рецептов (Recipe Book) - социальная сеть для хранения, поиска и создания кулинарных рецептов.

Если подробнее, то в ней будет:
-строка поиска по названию блюда (стандартный поиск)
-система оценивания рецептов (лайки/дизлайки)
-комментарии к рецептам
-личные кабинеты
-избранное
-добавление/удаление рецептов

Если с этим быстро управимся, то добавим ещё что-нибудь по типу главного экрана лучших рецептов за последние сутки и топ 1000 за всю историю, но это если быстро управимся.

## Технологии
Project: Gradle - Groovy  
Configuration: YAML  
Java: 21  
Spring Boot: 3.5.11  
Dependencies: Lombok, Spring Web, Spring Security, Liquibase Migration  
БД: postgresql
